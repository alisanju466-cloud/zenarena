# ZENOX ESPORTS

A responsive Free Fire custom-tournament frontend prototype using HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — website structure and pages
- `style.css` — premium black/red responsive design
- `app.js` — demo tournament data, filters, navigation, profile and support interactions

## Run locally
Open `index.html` in a browser. No build tools are required.

## Publish with GitHub Pages
1. Create a new GitHub repository named `zenox-esports`.
2. Upload `index.html`, `style.css`, `app.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Important prototype notes
- Tournament cards, player rankings, room states, profile stats and points are sample data.
- The wallet is a display-only demo-points interface. Points have no cash value and cannot be bought, transferred, withdrawn, or exchanged for money or prizes.
- Support form submissions are local demo confirmations only; no ticket is sent.
- GitHub Pages hosts static frontend files only. Real accounts, secure admin tools, live match data and persistent data require a separately built backend and database.
- This is an independent community project and is not affiliated with or endorsed by Garena.
